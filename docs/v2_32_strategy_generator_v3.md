# v2.32 Strategy Generator v3

v2.32 converts v2.31 governed feature evidence into deterministic Strategy DNA. It is a research/shadow generator, not an execution engine.

Pipeline:

`promoted PIT features -> family templates -> deterministic parameter variants -> feasibility -> research priority -> diversity selection -> frozen provenance -> validation handoff`

Every generated DNA contains universe, regime, setup features, entry/filter/exit conditions, stop, sizing and holding horizon. Generic conditions can be evaluated directly on a PIT feature panel. Generated candidates still require fast discovery, parameter search, purged walk-forward, cost stress, cross-engine validation and forward shadow before any later operational consideration.

No compliance gate is applied in research. No broker submission or live promotion is enabled.
